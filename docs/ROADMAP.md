# Neural Forms Roadmap

## Shipped

- Form builder (React admin UI)
- Gmail-style entry inbox
- AI analysis via Neural Forms Cloud (summary, category, priority, reply drafts, spam detection)
- CSV export with date-range filtering
- Email notifications (admin + autoresponder)
- CAPTCHA (Cloudflare Turnstile, Google reCAPTCHA v2)
- Reply system (email + message thread)

## Next

- Webhooks (outbound event hooks)
- CRM features
- Advanced form logic (conditional fields)
